# Changelog

All notable changes to Luroka are documented here.

## 1.0.0

### Added

- Cinematic home with artwork-led discovery, spotlight rotation, and personalized shelves
- Multi-server support — connect Plex, Jellyfin, and Emby side by side
- Screen time — viewing statistics with daily/weekly/monthly charts, streaks, and session history
- Watch Together — synchronized group viewing with room codes
- Kids profiles — parental controls, PIN protection, age gates, safe libraries, and a dedicated kids home
- Live preview in appearance settings — see changes before you commit
- Household management — profiles, per-person connections, and shared/server-side viewing
- Awards & festivals catalog — Oscar winners, BAFTA, Cannes, Emmy, Sundance selections
- Studio collections — browse movies and series by studio
- Person spotlight — filmography pages with posters and biography
- Advanced library filters — blacklist/whitelist per tracker, per library
- Companion remote — phone as remote control for your TV
- Discord Rich Presence integration
- Full Croatian translation
- Full Japanese translation
- Intro and credits skip with auto-detection
- Offline downloads with quality picker and transcoding support
- Live TV with DVR recording management
- Picture-in-Picture on mobile and desktop
- Ambient lighting synced to on-screen content
- Extended library filters per tracker service
- Multi-version playback with per-version file details

### Changed

- Unified settings architecture across mobile and TV with live preview
- Streaming quality naming clarified — "Original" as the default
- Force TV mode now uses a countdown confirmation to prevent accidental lockout
- TV screen margins default to 0% with an inline explanation

### Removed

- Legacy classic home design (replaced by cinematic home)
- Snackbars — success is silent, failures show as dialogs
- Issue-number comments from the upstream codebase
